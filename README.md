# Muse CLI Direct

Muse 的技能不是软件，只是一份给 AI 读的 Markdown 说明书。装技能就是复制文件夹，不用装别人写的包，Muse 直接调命令行，一样能做，还少一层风险。

这份 skill 整理了 8 个日常功能，全部用 Muse 已连接的命令行工具直接做：

1. 重要邮件检查：查 Gmail 和 Hotmail 当天新邮件，跳过促销，只留要回的
2. 每周复盘：列本周待办、截止日、等回音的线程，逐项核对最新状态
3. 对外分享先脱敏：发前搜一遍身份证号、电话、地址、卡号，有就删
4. 发货 / 交付前核验：按清单逐项对，不凭记忆说“发了”
5. 财务对账：发票、收据、银行流水三方对上，差额标出来
6. 历史价检查：查历史价、现价和到手总价，判断是不是高点
7. 记忆整理：删过期、冲突、重复的旧记录，只留还有效的
8. 发布前核实：每个说法回原出处核对一次，没来源就不写

## 在 Meta Muse 中使用

技能目录包含 `SKILL.md` 和 `skill.yaml`。在已有该目录的 Muse 工作区中，可以说：「请读取并按 `muse_cli_direct` 处理。」

例如，客户来问周五能否交付。私人待办可以保留联系人姓名，方便你跟进；给团队的转发草稿只保留交付问题。草稿先在聊天里展示，对外发送须有明确授权。

在一个 Muse 工作区中已确认手动读取新版，并用虚构资料验证邮件筛选、脱敏副本和记忆待处理清单。首次安装方式、自动加载及真实连接器尚未验证。

## 避坑

- 带 `--dangerously-skip-permissions` 的别装
- 满篇邀请码、推广链接的别装
- 教导出登录 Cookie、自动对外发消息的别装

一句话总结：技能包省的是写提示词的功夫，不是能力。能力本来就在命令行里，不用装，也能用。
